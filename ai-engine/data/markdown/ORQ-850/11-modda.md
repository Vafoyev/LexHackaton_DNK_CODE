# ORQ-850 11-modda: Tovarning monopol yuqori narxi

**Rasmiy Lex.uz havolasi:** [https://lex.uz/docs/-6518381#-6519611](https://lex.uz/docs/-6518381#-6519611)
**Bog'liq havolalar:** Mavjud emas

## Norma matni:
[ OKOZ: 1. 09.00.00.00 Tadbirkorlik va xoʻjalik faoliyati / 09.17.00.00 Savdo / 09.17.03.00 Savdoda narxni tartibga solish (shakllantirish) (shuningdek, 09.14.02.02ga qarang)] Agar tovarni realizatsiya qilish narxi hamda uni ishlab chiqarish va (yoki) realizatsiya qilish uchun zarur boʻlgan xarajatlar oʻrtasidagi tafovut juda yuqori boʻlsa yoki tovarning sifatini pasaytirish hisobidan qoʻshimcha foyda olishga qaratilgan boʻlsa, tovarning tovar yoki moliya bozorida ustun mavqega ega boʻlgan xoʻjalik yurituvchi subyekt tomonidan belgilanadigan narxi tovarning monopol yuqori narxidir. Tovarning narxi tovar-xomashyo birja savdolari yakunlariga koʻra shakllangan taqdirda, u monopol yuqori narx deb eʼtirof etilmaydi, bundan ustun mavqega ega boʻlgan xoʻjalik yurituvchi subyektlar ishtirokidagi hiyla-nayranglardan iborat harakatlar natijasida shakllangan narx mustasno. Bojxona ishi / 10.01.00.00 Tashqi iqtisodiy faoliyat sohasidagi umumiy qoidalar / 10.01.04.00 Eksport va import / 10.01.04.01 Eksport] Mazkur moddaning talablari eksport narxlariga nisbatan tatbiq etilmaydi. [ OKOZ: 1. 02.00.00.00 Davlat boshqaruvi asoslari / 02.01.00.00 Oʻzbekiston Respublikasi Vazirlar Mahkamasi (shuningdek, 01.11.00.00ga qarang) / 02.01.02.00 Vazirlar Mahkamasi vakolatlari] Tovarning monopol yuqori narxi Oʻzbekiston Respublikasi Vazirlar Mahkamasi tomonidan belgilangan tartibda aniqlanadi. Vazirlar Mahkamasining 2024-yil 1-maydagi 256-sonli “ Tovar va moliya bozorlarida monopoliyaga qarshi tartibga solishga doir normativ-huquqiy hujjatlarni tasdiqlash tugʻrisida ”gi qarori .
