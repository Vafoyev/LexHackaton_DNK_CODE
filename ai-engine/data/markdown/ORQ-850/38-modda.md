# ORQ-850 38-modda: Raqobat toʻgʻrisidagi qonunchilik buzilganligi haqidagi ish yuzasidan vakolatli davlat organining qarori

**Rasmiy Lex.uz havolasi:** [https://lex.uz/docs/-6518381#-6520329](https://lex.uz/docs/-6518381#-6520329)
**Bog'liq havolalar:** Mavjud emas

## Norma matni:
[ OKOZ: 1. 09.00.00.00 Tadbirkorlik va xoʻjalik faoliyati / 09.02.00.00 Raqobat toʻgʻrisida qonunchilik. Tabiiy monopoliyalar / 09.02.04.00 Monopoliyaga qarshi qonunchilik hujjatlarini buzganlik uchun javobgarlik] Vakolatli davlat organi raqobat toʻgʻrisidagi qonunchilik buzilganligi haqidagi ishni mohiyatiga koʻra koʻrib chiqish natijalari boʻyicha quyidagilar haqida qaror qabul qiladi: raqobat toʻgʻrisidagi qonunchilik buzilganligi fakti aniqlanganligi va tegishli huquqiy taʼsir choralari koʻrilishi haqida; ish yuritishni tugatish toʻgʻrisida. [ OKOZ: 1. 09.00.00.00 Tadbirkorlik va xoʻjalik faoliyati / 09.02.00.00 Raqobat toʻgʻrisida qonunchilik. Tabiiy monopoliyalar / 09.02.04.00 Monopoliyaga qarshi qonunchilik hujjatlarini buzganlik uchun javobgarlik] Vakolatli davlat organi: raqobat toʻgʻrisidagi qonunchilik buzilganligi faktlari tasdiqlanmagan; oʻziga nisbatan ish yuritilayotgan yuridik shaxs tugatilgan yoki jismoniy shaxs vafot etgan; raqobat toʻgʻrisidagi qonunchilik buzilishi oʻziga nisbatan ish qoʻzgʻatilgan xoʻjalik yurituvchi subyekt, respublika ijro etuvchi hokimiyat organlari va boshqa tashkilotlar, yuridik shaxslarning birlashmalari tomonidan ixtiyoriy ravishda bartaraf etilgan; vakolatli davlat organi koʻrib chiqayotgan raqobat toʻgʻrisidagi qonunchilik buzilganligi haqidagi ish yuzasidan sud tomonidan qaror qabul qilingan taqdirda, raqobat toʻgʻrisidagi qonunchilik buzilganligi haqidagi ishni yuritishni tugatadi. [ OKOZ: 1. 09.00.00.00 Tadbirkorlik va xoʻjalik faoliyati / 09.02.00.00 Raqobat toʻgʻrisida qonunchilik. Tabiiy monopoliyalar / 09.02.04.00 Monopoliyaga qarshi qonunchilik hujjatlarini buzganlik uchun javobgarlik] Vakolatli davlat organining raqobat toʻgʻrisidagi qonunchilik buzilganligi haqidagi ish yuzasidan qarori darhol eʼlon qilinishi kerak. [ OKOZ: 1. 09.00.00.00 Tadbirkorlik va xoʻjalik faoliyati / 09.02.00.00 Raqobat toʻgʻrisida qonunchilik. Tabiiy monopoliyalar / 09.02.04.00 Monopoliyaga qarshi qonunchilik hujjatlarini buzganlik uchun javobgarlik] Oʻziga nisbatan qaror qabul qilingan shaxsga vakolatli davlat organining raqobat toʻgʻrisidagi qonunchilik buzilganligi haqidagi ish yuzasidan qaroriga asosan koʻrsatma beriladi.
