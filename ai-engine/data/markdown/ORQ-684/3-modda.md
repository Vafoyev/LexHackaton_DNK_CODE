# ORQ-684 3-modda: Davlat xaridlari toʻgʻrisidagi qonunchilik

**Rasmiy Lex.uz havolasi:** [https://lex.uz/docs/-5382974#-5384378](https://lex.uz/docs/-5382974#-5384378)
**Bog'liq havolalar:** Mavjud emas

## Norma matni:
[ OKOZ: 1. 02.00.00.00 Davlat boshqaruvi asoslari / 02.08.00.00 Iqtisodiyot, ijtimoiy-madaniy qurilish sohasidagi davlat boshqaruvining umumiy masalalari / 02.08.02.00 Davlat ehtiyojlari. Davlat xaridlari] Davlat xaridlari toʻgʻrisidagi qonunchilik ushbu Qonun va boshqa qonunchilik hujjatlaridan iboratdir. [ OKOZ: 1. 19.00.00.00 Xalqaro munosabatlar. Xalqaro huquq / 19.06.00.00 Xalqaro shartnomalar huquqi / 19.06.01.00 Umumiy masalalar] Agar Oʻzbekiston Respublikasining xalqaro shartnomasida Oʻzbekiston Respublikasining davlat xaridlari toʻgʻrisidagi qonunchiligida nazarda tutilganidan boshqacha qoidalar belgilangan boʻlsa, xalqaro shartnoma qoidalari qoʻllaniladi.
