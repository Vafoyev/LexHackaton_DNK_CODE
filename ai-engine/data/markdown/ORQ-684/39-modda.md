# ORQ-684 39-modda: Takliflarni taʼminlash

**Rasmiy Lex.uz havolasi:** [https://lex.uz/docs/-5382974#-5385552](https://lex.uz/docs/-5382974#-5385552)
**Bog'liq havolalar:** Mavjud emas

## Norma matni:
[ OKOZ: 1. 02.00.00.00 Davlat boshqaruvi asoslari / 02.08.00.00 Iqtisodiyot, ijtimoiy-madaniy qurilish sohasidagi davlat boshqaruvining umumiy masalalari / 02.08.02.00 Davlat ehtiyojlari. Davlat xaridlari; 2. 03.00.00.00 Fuqarolik qonunchiligi / 03.10.00.00 Majburiyat huquqi / 03.10.02.00 Majburiyatlarning bajarilishini taʼminlash / 03.10.02.02 Garov; 3. 03.00.00.00 Fuqarolik qonunchiligi / 03.10.00.00 Majburiyat huquqi / 03.10.02.00 Majburiyatlarning bajarilishini taʼminlash / 03.10.02.05 Kafolat; 4. 03.00.00.00 Fuqarolik qonunchiligi / 03.10.00.00 Majburiyat huquqi / 03.10.02.00 Majburiyatlarning bajarilishini taʼminlash / 03.10.02.06 Zakalat] Xarid komissiyasi ishtirokchilarga nisbatan takliflarning garov, kafolat, zakalat tarzida yoxud qonunchilikda nazarda tutilgan boshqa usulda taʼminlanishi zarurligi toʻgʻrisidagi talabni belgilashga haqli. Ishtirokchilarga nisbatan takliflarning taʼminlanishi zarurligi tarzidagi talab barcha ishtirokchilarga taalluqli boʻladi va davlat xaridlarining shartlarida koʻrsatiladi. Xarid komissiyasi ishtirokchilarga nisbatan takliflarning taʼminlanishi zarurligi tarzida talab belgilagan taqdirda, takliflar yuborilguniga qadar ishtirokchi davlat buyurtmachisiga taʼminotning maqbulligini tasdiqlash toʻgʻrisida soʻrov yuborishga haqli. Davlat buyurtmachisi bunday soʻrovga ikki ish kuni davomida javob beradi. Davlat buyurtmachisi taklifni taʼminlash summasi toʻlanishini talab qilmaydi va taʼminlash toʻgʻrisidagi hujjatni bir ish kuni davomida qaytaradi yoki quyidagi voqealardan biri yuz berganidan keyin uning qaytarilishini taʼminlaydi: taklifni taʼminlashning amal qilish muddati tugashi; shartnomaning kuchga kirishi va ushbu shartnomaning bajarilishi taʼminlanishi, agar bunday taʼminlash davlat xaridi shartlarida talab etilsa; davlat xaridlarining bekor qilinishi; takliflarni yuborishning oxirgi muddati tugaguniga qadar taklifning chaqirib olinishi.
